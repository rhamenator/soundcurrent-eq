# Updates and profile navigation

Install a newer package over the existing installation; no uninstall is required.
Save your work, choose **Quit** (closing the window can leave processing running),
install, then reopen. Settings and custom profiles remain in the user configuration.

Settings offers update reminders, preview-release selection, manual checking, and a
configurable download folder. Release checks use HTTPS GitHub metadata; they never
automatically download or execute an installer. Private Studio releases require
GitHub access in your browser. Local matching installers are detected independently.
A running app checks every 30 seconds for an installed-binary change and reminds you
to Quit and reopen.

The speaker selector filters by **Manufacturer** and **Type**. Browsing filters does
not apply correction. An active or restored selection remains visible outside the
filters. The equipment library also filters speaker/microphone/amplifier kind and
family, and exposes editable subtype and active/passive metadata. Unknown types stay
explicitly unclassified. Editing a published profile saves a custom copy.
