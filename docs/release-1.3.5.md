# SoundCurrent EQ 1.3.5

- Scroll back in time on the spectrogram and waveform: Shift+wheel or a horizontal wheel, or drag in the waveform (Shift+drag in the spectrogram). Scrolling back freezes the display; double click or unchecking Freeze returns to live. Axis labels follow the offset.
- New Save image button writes the current analysis display to a PNG.
- New Brown noise calibration signal (-6 dB/octave, mostly bass) next to pink and white noise; it plays 6 dB below the chosen level. Its few treble bands usually report not enough signal.
- The Tuner shows the detected chord instead of a meaningless single-note readout when several notes sound, with a pitch-class strip above and the tuning gauge below.
- Translations for the new text are included in all 33 language catalogs (linguistic accuracy unverified).

## Upgrade

Use **Quit**, then install 1.3.5 over the existing application. Settings and custom profiles are retained. The public Windows package continues to use the interim VB-CABLE route; the unsigned native-driver implementation remains preserved for later production signing.
