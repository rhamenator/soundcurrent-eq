# SoundCurrent EQ 1.3.2

- Make the Equalizer and configuration pages adapt cleanly to small screens, larger display scaling, long translations, and right-to-left layouts.
- Keep the equalizer band strip horizontally scrollable without widening the whole page. Band columns now use deterministic sizing, including a tested 15-to-16-band transition that does not resize or overlap existing sliders.
- Make listening-preset, selected-band, device, language, update, and analyzer controls wrap responsively when space is limited.
- Add automated appearance and scaling coverage for 800×600, 200% scaling, pseudolocalized text, and all 34 localization catalogs.

## Upgrade

Use **Quit**, then install 1.3.2 over the existing application. Settings and custom profiles are retained. Audio processing and driver behavior are unchanged.
