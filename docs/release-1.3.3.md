# SoundCurrent EQ 1.3.3

- Improve responsive control sizing and equalizer-band behavior on smaller or high-DPI displays.
- Keep the selected spectrogram advancing through silence while leaving hidden analysis views inactive.
- Reduce visualization refresh pressure and bound high-DPI spectrogram history without blocking audio processing.
- Preserve microphone-response accumulation cadence and improve automated coverage for silent analysis, band-count changes, and all localization catalogs.

## Upgrade

Use **Quit**, then install 1.3.3 over the existing application. Settings and custom profiles are retained. The public Windows package continues to use the interim VB-CABLE route; the unsigned native-driver implementation remains preserved for later production signing.
