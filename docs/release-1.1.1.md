- Complete localization catalog coverage and regional formatting fixes, including translated calibration-worker diagnostics. Native-speaker verification remains unverified.
- Direct speaker, microphone and amplifier profile management: create, import, edit, export, apply and delete user profiles with confirmation. Bundled measurements are protected.

Install over the existing application. Quit the active equalizer first; closing its window may leave processing running. Only one equalizer should process audio at a time.

Linux packages target Ubuntu 24.04 or compatible Debian, Fedora 44, and RHEL 10-compatible distributions. Windows installers retain the interim VB-CABLE setup and recovery guidance. Physical Windows driver/audio qualification remains limited to existing evidence.
