## External prerequisite

A Microsoft developer/Store account alone does not establish Hardware Developer Program enrollment or an eligible signing certificate. The verified production route requires identity/enrollment and certificate prerequisites, then Microsoft driver signing and the relevant certification/testing route. The privileged manager also needs verified Authenticode signing. See the repository Windows signing documentation. No certificate purchase, account enrollment or submission has been performed. This prerequisite prevents signed driver runtime/lifecycle testing; it does not excuse remaining userspace tests that can run safely now.
